Making scenes (steps 5 to 7). Each scene goes through the Higgsfield connector on the plan’s credits, with the same five steps every time (up to three at a time when they do not depend on each other):
   - Price. Call generate_video with get_cost: true and the exact parameters you will send; credits_exact in the answer is the price (book that number, not a rounded one) and nothing is submitted. If the answer is a notice that suggests a preset (preset_recommendation) instead of a price, never use the preset: call again with the same parameters plus declined_preset_id set to the preset id in the notice, and use that answer; send declined_preset_id on the real call too. A model you have not used yet: call models_explore with action get and its model_id first; it lists the parameters, the media roles and the aspect ratios, and you send only what it lists.
   - Book it, before it is sent. The model id is the one you call (kling4_0), the credits are the price, --seconds is the scene’s length:
    node "{{shotsScript}}" book "{{editDir}}" A --kind clip --model kling4_0 --credits 8 --budget {{budgetNumber}} --seconds 16
     The answer’s spentUsd and leftUsd are the truth about the money. Exit 2, over_budget: nothing was booked, so do not make it. Asked again for a take that is already booked it answers reused: true with its state: completed with a file means it is done (use the file, never make it again); booked with a requestId means a request is already running (go to the wait with that id); booked with no requestId means it was never sent (go on).
   - Make it: the same call without get_cost, with use_unlim: false and no folder_id. It answers a job id. At once book the same take again with the job id added, so a rerun waits for this request instead of making and paying for it again:
    node "{{shotsScript}}" book "{{editDir}}" A --kind clip --model kling4_0 --credits 8 --budget {{budgetNumber}} --seconds 16 --job 9f1c2e7a
     A refusal that says there are no credits left is the end of the money (see Blocked below); any other refusal charged nothing: read what it says, fix the parameters and make it again.
   - Wait: jobs_wait with the job id; while all_terminal is false, call it again after poll_after_seconds. A scene of 14 to 16 seconds takes about four minutes.
   - Save it. Completed: the result url jobs_wait gave goes in single quotes. The script downloads the file, checks it is a video, takes its soundtrack out and puts it where it belongs, and answers its file:
    node "{{shotsScript}}" save "{{editDir}}" A --kind clip --url 'https://result.example/clip.mp4' --job 9f1c2e7a
     Failed, nsfw or canceled (nothing is charged): void the booking, then make it again as a new take (--take 2, then 3) with a plainer prompt:
    node "{{shotsScript}}" void "{{editDir}}" A --kind clip --reason 'what jobs_wait said'
   A scene is kind clip: its take is clips/<id>/take-N.mp4. --take is 1 unless you make the same scene again; a new take is --take N+1.
