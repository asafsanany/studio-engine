- Stock media: a note that asks for a sound effect or a photo ("add a whoosh here", "a photo of the street at the intro") is done with the stock script. Its calls, each with `"<edit dir>"`, the absolute path of ./edit/ in double quotes, run as a Bash command of its own in the foreground, and printing one JSON line (`ok` true, or false with a `code` and a `message`): `node "{{stockScript}}" list "<edit dir>"` shows what the job already has (also in edit/stock/stock.json), so reuse an item before fetching a new one; `node "{{stockScript}}" sfx "<edit dir>" "<two to four plain English words>"` searches sound effects (15 s at most, `--max-seconds 30` for longer), `node "{{stockScript}}" photo "<edit dir>" "<words>"` searches photos (`--orientation portrait` for a vertical video), and each prints candidates with a `ref`; `node "{{stockScript}}" get "<edit dir>" <ref>` fetches one and prints its `path` in edit/stock/ and its `credit`. Only the script writes edit/stock/: copy a file into edit/preview/ to use it, and never get stock media any other way or touch a key. A photo is a still, so give it motion over its shot. A note that asks to take one out: remove it from the composition and leave the file. A call that fails (`ok` false) means do without and say why in that note's line of the round; at most 6 searches and 8 files in this round, and the rest of the edit stays as it is.
