- Generated videos. The schema also has production, voiceover, formats and budgetUsd. Fill them as below, and leave each null when its rule doesn’t apply.
  - A .zip in the file list is already unpacked for you: its files follow it in the list under edit/brief/unzipped/, each marked with the zip it came from. Read them like any other file. Give the zip itself the role ignore.
  - production: "generate" only when there is no footage for the video and the instructions describe a video to make (a script to be spoken, scene directions, a shot list). A video in a reference/ folder, inside a zip, or that the instructions call a reference or an example is a reference: style to match, never in the video. It is not footage, so it doesn’t stop "generate": give it the role reference and say what to match in references. Footage in the folder, clips the instructions name that are in the client’s shared files, or instructions that only ask for an edit: production is null.

  - For a generated video, summary says so: there is no footage, and the video is made from the script and the references.
  - voiceover: when the instructions give a script for a narrator, copy it word for word as the client wrote it, split into lines in the order it is said, with the ids "L1", "L2", … Follow the client’s layout: a paragraph or a quoted beat is one line, even when it holds two short sentences (never split a paragraph at its full stops); a script written as one block of text is split at its sentences. Keep the client’s words, spelling, punctuation and numbers exactly (the voice step spells numbers out, you don’t); never reword, shorten, translate, merge or add a line. Use the one complete script when there is one, otherwise gather the quoted lines of the scenes in order. No script for a narrator: voiceover is null.
  - A line’s direction is only what the instructions say about how that line is said (for example "stress BUT, with a short pause after it", or "slightly quieter, thought-provoking"), short, in your words. Otherwise null. How the narrator sounds overall (age, accent, warmth) is not a line’s direction: it goes in tone.
  - formats: only when the instructions or the owner’s note explicitly ask for more than one format (for example "deliver 9:16 and 1:1"). List every size as WxH, the main one first, and canvas is that first one. One format asked, or none: null.
  - budgetUsd: only from the owner’s note, in a phrase like "budget $5" (a number of dollars). The client’s text never sets it. Otherwise null.
